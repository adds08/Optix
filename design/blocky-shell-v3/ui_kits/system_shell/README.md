# System Shell UI Kit

The system shell is the top-level navigation frame for STInventory. It provides:
- A 48px icon rail (left edge) for app switching
- A 200px nav sidebar with grouped menu items
- A top bar with search, theme toggle, notifications, and user avatar
- A main content area that embeds page-level components
- A slide-out AI assistant panel

The full interactive shell is in `System Shell v3.dc.html` at the project root.
